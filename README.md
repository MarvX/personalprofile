# سایت احسان — نسخه اولیه

داشبورد شخصی فارسی و راست‌چین برای مدیریت روز، وظایف، عادت‌ها، هدف‌ها و ماژول‌های زندگی. این نسخه به‌صورت وب‌سایت استاتیک و سبک شروع شده تا آن را مرحله‌به‌مرحله در همین مخزن توسعه بدهیم.

## اجرا
- فایل index.html را برای پیش‌نمایش ساده باز کنید.
- برای تست PWA و Service Worker، سایت را روی یک میزبان HTTPS مانند Vercel منتشر کنید.
- نیازی به build command یا نصب پکیج نیست؛ فایل‌ها در ریشه مخزن هستند.

## قابلیت‌های فعال
- داشبورد «امروز من» با تم Sage و حالت روشن/تاریک
- ناوبری بخش‌ها و چیدمان واکنش‌گرا برای موبایل و دسکتاپ
- افزودن، انجام‌شده‌کردن و حذف وظایف
- ثبت عادت‌ها و هدف‌ها و تغییر درصد پیشرفت
- ثبت تعداد واژه‌های روزانه و صفحات مطالعه
- خروجی JSON از وضعیت محلی
- manifest و service worker اولیه برای PWA

## محدودیت‌های مهم
- داده‌ها در این نسخه با localStorage همان مرورگر ذخیره می‌شوند؛ هنوز بین دستگاه‌ها همگام نمی‌شوند و نباید برای اطلاعات حساس یا چندکاربره استفاده شوند.
- ثبت‌نام، تأیید مدیر، احراز هویت، دیتابیس، ذخیره فایل ابری و سیاست‌های دسترسی هنوز پیاده‌سازی نشده‌اند.
- اتصال هوش مصنوعی، اعلان پوش، تقویم واقعی، گزارش‌های مالی و ورزشی کامل، مرور G5 و پیام‌رسان/تماس زنده پارتنر در مراحل بعد اضافه می‌شوند.
- اعداد و وظایف اولیه نمونه قابل‌ویرایش‌اند؛ اطلاعات واقعی کاربر نیستند.
- پیش از استفاده چندکاربره باید backend امن، کنترل دسترسی سمت سرور، مدیریت اسرار در متغیرهای محیطی و پشتیبان‌گیری طراحی و آزمایش شود.

## نقشه توسعه پیشنهادی
1. انتخاب دیتابیس کم‌هزینه، احراز هویت و تأیید ثبت‌نام توسط مدیر و جداسازی اطلاعات کاربران.
2. ذخیره‌سازی پایدار و فرم‌های کامل وظایف، عادت‌ها، اهداف، تقویم و تنظیمات.
3. ورزش و سلامت، مالی، دانشگاه/معماری، زبان و مطالعه.
4. هوش مصنوعی با تأیید قبل از هر تغییر و کنترل هزینه.
5. فضای پارتنر، اشتراک‌گذاری انتخابی، پیام‌رسانی و سپس ارزیابی تماس زنده.
6. اعلان‌های گوشی، خروجی/بازیابی کامل، تست امنیت و انتشار.
